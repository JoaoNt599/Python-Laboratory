# ORM - SQLAlchemy


## ORM 

### An ORM (Object-Relational Mapper) is a tool that allows developers to interact with a relational database using objects and classes instead of writing raw SQL queries.

### It maps:

- Tables -> Classes

- Rows -> Objects

- Columns -> Attributes

### This lets you work with the database using the programming language’s syntax, making the code more readable, maintainable, and less error-prone.


## SQLAlchemy?

### SQLAlchemy is a powerful and flexible Python ORM and SQL toolkit.

### It provides:

- A Core layer, which lets you write SQL expressions programmatically

- An ORM layer, which maps Python classes to database tables and handles CRUD operations using objects


### SQLAlchemy is widely used because it:

- Supports multiple databases (PostgreSQL, MySQL, SQLite, MSSQL, etc.)

- Gives fine control over SQL when needed

- Scales well from small projects to large, complex systems
